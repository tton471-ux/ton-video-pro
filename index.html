3. เลือกโหมดส่งออก

HDR Safe จะส่งออกไฟล์ต้นฉบับเดิมเมื่อพบ HDR หรืออ่านข้อมูลไม่ครบ จึงไม่ลดขนาดไฟล์และไม่เปลี่ยน FPS ส่วน SDR Optimizer ใช้ H.264 8-bit เท่านั้น ห้ามใช้กับ HDR
HDR Experimental เป็นการทดสอบเข้ารหัสใหม่ ไม่รับประกันการคง mastering-display / MaxCLL / Dolby Vision dynamic metadata ทุกชนิด ให้เก็บต้นฉบับไว้เสมอ และตรวจสอบไฟล์ผลลัพธ์ก่อนใช้งานจริง
HDR Experimental จะทำงานเฉพาะเมื่อพบ HDR + 10-bit + BT.2020 + PQ/HLG และมี libx265 ให้เลือก หากเงื่อนไขไม่ครบ ระบบจะหยุดเพื่อความปลอดภัย
เลือกไฟล์และวิเคราะห์ก่อนเริ่มประมวลผล

4. ผลลัพธ์

ข้อจำกัดที่ต้องทราบ

V3.2.4 ตรวจสอบการมีอยู่ของ libx265 ก่อน แต่การพบ encoder เพียงอย่างเดียวยังไม่รับประกันการรักษา HDR10/HLG หรือ dynamic metadata จึงยังไม่เปิด HDR re-encode จนกว่าจะมีการทดสอบ end-to-end กับไฟล์ตัวอย่าง การรักษา HDR Safe คือคัดลอกไฟล์เดิมโดยไม่เข้ารหัสซ้ำ การแปลง 60 เป็น 120 FPS ไม่ใช่ AI Frame Interpolation และ TikTok ยังสามารถเข้ารหัสไฟล์ใหม่ได้

ใช้ผ่าน HTTPS และ Chrome/Edge รุ่นใหม่ การวิเคราะห์ต้องโหลด FFmpeg.wasm จาก CDN ในครั้งแรก หากเครือข่ายบล็อก CDN จะแสดงขั้นตอนที่ล้มเหลว
